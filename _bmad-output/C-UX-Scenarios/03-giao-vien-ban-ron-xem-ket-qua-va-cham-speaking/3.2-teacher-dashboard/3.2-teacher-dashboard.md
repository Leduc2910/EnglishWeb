## Overview

**Page Purpose:** Cho giáo viên thấy tổng quan bài nộp và chuyển vào module "Kết quả".

**User Situation:** Giáo viên muốn kiểm tra nhanh có bao nhiêu bài đã nộp, bài Speaking nào còn chờ chấm, rồi vào xử lý.

**Success Criteria:** Giáo viên nhận ra có việc cần xử lý và chọn "Kết quả" trên navbar trong một thao tác.

**Entry Points:**
- Redirect after login.
- Return from Results module.

**Exit Points:**
- `/teacher/results` via navbar.
- `/teacher/library` via "Thư viện đề" navbar item when teacher wants to inspect source templates.

---

## Layout Structure

```text
+--------------------------------------------------+
| App nav: Dashboard | Thư viện đề | Lớp | Kết quả |
+--------------------------------------------------+
| Header: Tổng quan giáo viên + class filter       |
+----------------+----------------+----------------+
| Submissions    | Auto-graded    | Speaking todo  |
+--------------------------------------------------+
| Recent submissions / grading queue preview       |
+--------------------------------------------------+
```

**Layout intent:** Dashboard gives a useful pulse, but the actual grading work lives in module "Kết quả". Navbar remains consistent with the corrected model: "Thư viện đề" is the template library.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Metrics fetching | Skeleton cards/table | Wait |
| Default | Data available | Metrics and preview visible | Navigate/filter |
| Empty | No submissions yet | Zero metrics and calm empty state | Check later |
| Error | Data fails | Retry banner | Retry/navigate |

## Validation & Errors

| Check | Rules | Timing | Error |
|-------|-------|--------|-------|
| Teacher session | Authenticated teacher required | Page load | `ERR_TEACHER_AUTH_REQUIRED`: "Vui lòng đăng nhập lại." |
| Class filter | Must be one of teacher's classes | Change/load | `ERR_CLASS_FILTER_INVALID`: "Bộ lọc lớp không hợp lệ." |
| Results metrics access | Teacher can only see submissions for assigned classes/templates/sessions | Data fetch | `ERR_RESULTS_METRICS_ACCESS`: "Bạn không có quyền xem dữ liệu kết quả này." |

## Technical Notes

- Keep "Kết quả" navbar item persistent and predictable.
- Speaking pending count should match the filtering logic in Results module.
- Recent rows should preserve whether the submission came from HomeworkAssignment or LiveExamSession.
