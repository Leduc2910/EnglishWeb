## Overview

**Page Purpose:** Giúp giáo viên lọc kết quả theo lớp, đề, dạng bài (Homework/Thi trực tiếp), mở đúng submission, nghe file Speaking, nhập điểm và feedback trong cùng một màn hình.

**User Situation:** Giáo viên cần xử lý kết quả sau khi học sinh nộp, đặc biệt các bài Speaking chưa chấm thủ công.

**Success Criteria:** Giáo viên tìm được submission cần xử lý, nghe file trực tiếp, lưu điểm/feedback, và thấy trạng thái đã chấm cập nhật ngay.

**Entry Points:**
- Navbar "Kết quả" từ Teacher Dashboard.
- Metric/card link from dashboard queue preview.

**Exit Points:**
- Stay on page after saving and move to next submission.
- Open student/test detail if needed.

## Interactions

| Object ID | Trigger | Behavior |
|-----------|---------|----------|
| `results-grading-class-filter` | Change | Refetch results and clear selected detail if no longer valid. |
| `results-grading-type-filter` | Change | Filters result rows by homework or live exam session. |
| `results-grading-test-filter` | Change | Narrows result table. |
| `results-grading-student-search` | Input | Debounced table filter. |
| `results-grading-row` | Click | Opens selected submission in detail panel. |
| `results-grading-speaking-player` | Play/pause/seek | Plays submitted file without leaving page. |
| `results-grading-save-button` | Click | Validates score/feedback, saves grading data, updates row status. |
| `results-grading-next-pending-button` | Click | Opens next Speaking submission with `Needs grading` status. |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Fetching results | Table skeleton, detail empty | Wait |
| Default | Results loaded | Table + optional detail | Filter/open/save |
| No selection | Table loaded, no row selected | Detail placeholder | Select row |
| Empty | No matching results | Empty table message | Clear filters |
| Saving | Grading save pending | Save button loading, inputs disabled lightly | Wait |
| Save success | Feedback saved | Toast/status and row badge updated | Move next |
| Error | Fetch/audio/save fails | Contextual error banner | Retry |

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| Score | Required for Speaking grading, numeric, within configured max | Save | `ERR_SCORE_INVALID`: "Nhập điểm Speaking hợp lệ." |
| Feedback | Optional for MVP, max 2000 chars | Save | `ERR_FEEDBACK_TOO_LONG`: "Feedback quá dài." |
| Submission | Must be selected and belong to teacher's class/test | Open/save | `ERR_SUBMISSION_ACCESS`: "Bạn không có quyền mở submission này." |
| Audio file | Must be available for Speaking submission | Detail load/play | `ERR_SPEAKING_FILE_MISSING`: "Không tìm thấy file Speaking." |

---

## Technical Notes

- Reading/Listening rows display auto score from answer key; Speaking rows require manual score.
- Results should preserve the distinction between HomeworkAssignment and LiveExamSession for filtering and reporting.
- Save operation should be autosafe: no double-submit, clear saved timestamp.
- Keep audio player, score, and feedback visible together.
- Export is out of MVP unless later prioritized.
