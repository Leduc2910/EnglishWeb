## Overview

**Page Purpose:** Giúp giáo viên nhập số câu, đáp án đúng và điểm để hệ thống tự chấm Reading.

**User Situation:** Giáo viên đã upload PDF và cần khai báo answer key nhanh mà không nhập lại nội dung đề.

**Success Criteria:** Answer key đầy đủ, điểm hợp lệ, giáo viên thấy cảnh báo rõ trước khi review.

**Entry Points:**
- Continue from Upload Materials.
- Resume draft at answer-key step.

**Exit Points:**
- Continue to Review Template & Next Action.
- Back to Upload Materials.

## Interactions

| Object ID | Trigger | Behavior |
|-----------|---------|----------|
| `answer-key-question-count-input` | Change | Generates/removes rows after confirmation if reducing count. |
| `answer-key-scoring-mode-control` | Change | Switches between total score and per-row score inputs. |
| `answer-key-answer-input` | Input | Saves row draft and updates missing-answer count. |
| `answer-key-score-input` | Input | Recalculates total score. |
| `answer-key-continue-button` | Click | Validates all rows and scoring, then routes to review. |

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| Question count | Required integer 1-200 | Change + submit | `ERR_QUESTION_COUNT_INVALID`: "Số câu phải từ 1 đến 200." |
| Answer | Required for every question | Submit | `ERR_ANSWER_MISSING`: "Câu {n} chưa có đáp án." |
| Total score | Required > 0 when equal scoring | Submit | `ERR_TOTAL_SCORE_INVALID`: "Tổng điểm phải lớn hơn 0." |
| Per-question score | Required > 0 for every row when enabled | Submit | `ERR_ROW_SCORE_INVALID`: "Điểm câu {n} phải lớn hơn 0." |

---

## Technical Notes

- Store answer key as structured rows independent from PDF page content.
- Support autosave; never lose typed answers on navigation warning.
- Consider paste-to-grid later, but keep MVP manual entry reliable first.
