## Overview

**Page Purpose:** Thu thập thông tin nền tảng của **đề gốc**: tên đề và kỹ năng. Lớp, hạn nộp và phiên thi được cấu hình sau khi dùng đề để giao homework hoặc tạo thi trực tiếp.

**User Situation:** Giáo viên đã bắt đầu tạo đề gốc mới trong Thư viện đề và cần nhập cấu hình tối thiểu trước khi upload PDF/audio/cue card.

**Success Criteria:** Giáo viên hoàn tất cấu hình hợp lệ trong thời gian ngắn và hiểu đây là bước 1 của workflow.

**Entry Points:**
- Button "Tạo bài test" từ Test Library.
- Resume draft from Test Library.

**Exit Points:**
- Continue to Upload Materials.
- Save draft and return to Test Library.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | New draft | Empty required fields | Fill form |
| Saving | Autosave/manual save pending | Draft status spinner | Keep editing |
| Saved | Save succeeds | "Đã lưu nháp" status | Continue |
| Error | Save or validation fails | Inline field errors + banner | Fix/retry |

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| Template name | Required, 3-120 chars | Blur + submit | `ERR_TEMPLATE_NAME_REQUIRED`: "Nhập tên đề." |
| Skill | Required | Submit | `ERR_SKILL_REQUIRED`: "Chọn kỹ năng cho bài test." |
| Tags | Optional, max 10 tags | Submit | `ERR_TAG_LIMIT`: "Tối đa 10 tag cho một đề." |

---

## Technical Notes

- Create draft template record as soon as teacher continues.
- Reading flow must not ask teacher to parse or re-enter PDF content.
- Class/deadline/time-limit are not configured here; they belong to HomeworkAssignment or LiveExamSession.
- Autosave status should not block typing.
