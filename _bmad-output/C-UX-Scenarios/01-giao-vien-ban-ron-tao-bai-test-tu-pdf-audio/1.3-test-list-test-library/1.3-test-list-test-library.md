## Overview

**Page Purpose:** Giúp giáo viên quản lý **Thư viện đề**: kho đề gốc có PDF/audio/cue card, answer key và thang điểm; từ mỗi đề có thể giao homework hoặc tạo phiên thi trực tiếp.

**User Situation:** Giáo viên đã chọn module "Thư viện đề" và đang tìm đường ngắn nhất để tạo đề gốc từ tài liệu có sẵn, hoặc dùng lại đề đã có cho homework/thi trực tiếp.

**Success Criteria:** Giáo viên thấy danh sách đề gốc, lọc nhanh, tạo đề mới, hoặc chọn một đề để giao homework/tạo phiên thi trực tiếp.

**Entry Points:**
- Navbar "Thư viện đề" từ Teacher Dashboard.
- Breadcrumb/module nav từ các trang tạo test.

**Exit Points:**
- `/teacher/library/new/setup` khi chọn tạo đề mới.
- Template detail/edit nếu mở đề gốc có sẵn.
- Homework assignment flow hoặc live exam session flow nếu chọn hành động dùng đề.

## Page Sections

### Section: Module Header

**OBJECT ID:** `question-library-header`

| Object | Type | Content / Behavior |
|--------|------|--------------------|
| `question-library-title` | Heading | "Thư viện đề". |
| `question-library-create-button` | Primary button | Text: "Tạo đề mới"; routes to setup step. |

### Section: Filters

**OBJECT ID:** `question-library-filters`

| Object | Type | Content / Behavior |
|--------|------|--------------------|
| `question-library-search-input` | Search input | Placeholder: "Tìm theo tên đề". |
| `question-library-skill-filter` | Segmented/select | All, Reading, Listening, Speaking. |
| `question-library-status-filter` | Select | Draft, Ready, Archived. |

**OBJECT ID:** `question-library-table`

| Object | Type | Content / Behavior |
|--------|------|--------------------|
| `question-library-template-row` | Table row | Shows template name, skill, status, last used date and usage count. |
| `question-library-row-actions` | Menu | Edit template, duplicate, archive, assign homework, create live exam. |
| `question-library-empty-state` | Empty state | Guides teacher to create first template using main button. |

## Interactions

|-----------|---------|----------|

| `question-library-search-input` | Input | Debounced filter by template name. |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Template list fetching | Table skeleton | Wait |
| Default | Templates exist | Filter bar + table | Create, filter, open rows, use template |
| Empty | No templates match | Empty state under filters | Clear filters or create template |
| Error | Fetch fails | Retry banner above table | Retry |

## Validation & Errors

| Input | Rules | Error |
|-------|-------|-------|
| Search | Max 100 chars | `ERR_SEARCH_TOO_LONG`: "Từ khóa tìm kiếm quá dài." |
| Filters | Must be valid option from API | `ERR_FILTER_INVALID`: "Bộ lọc không hợp lệ." |
| Use template | Template must be ready before assignment/session | `ERR_TEMPLATE_NOT_READY`: "Đề chưa sẵn sàng để sử dụng." |

## Technical Notes

- Persist filter state in query params.
- Preserve template status badges consistently across wizard review.
- A template is not a homework or live exam by itself; assignment/session creation is a separate action.
