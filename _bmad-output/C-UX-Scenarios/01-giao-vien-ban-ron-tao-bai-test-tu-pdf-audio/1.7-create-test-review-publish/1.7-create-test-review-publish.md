## Overview

**Page Purpose:** Cho giáo viên kiểm tra cấu hình đề gốc, đánh dấu đề sẵn sàng sử dụng, rồi chọn dùng đề để giao homework hoặc tạo phiên thi trực tiếp.

**User Situation:** Giáo viên đã có tên đề, PDF và answer key hợp lệ; mối lo chính là lưu sai đề gốc khiến các homework/phiên thi sau bị sai theo.

**Success Criteria:** Giáo viên thấy mọi điều kiện đề gốc đã sẵn sàng, lưu thành công, và có hai hành động rõ: Giao homework hoặc Tạo phiên thi trực tiếp.

**Entry Points:**
- Continue from Answer Key & Scoring.
- Resume draft at review step.

**Exit Points:**
- Save-ready success: template detail or Question Library with success toast.
- Next action: Homework assignment flow or Live exam session flow.
- Back to previous steps for correction.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Ready | All required checks pass | Mark-ready button enabled, checklist green | Mark ready |
| Blocking issue | Missing/invalid config | Mark-ready disabled or focuses issue | Edit relevant step |
| Saving ready state | Request pending | Modal/button loading | Wait |
| Save error | API fails | Error banner with retry | Retry/save draft |
| Success | Template is ready | Success banner with homework/live exam next actions | Use template or return library |

## Validation & Errors

| Check | Rules | Timing | Error |
|-------|-------|--------|-------|
| Template info | Name and skill are present | Page load + mark ready | `ERR_TEMPLATE_INFO_MISSING`: "Thông tin đề chưa đầy đủ." |
| PDF | Uploaded file exists and is available | Page load + mark ready | `ERR_REVIEW_PDF_MISSING`: "Chưa có file PDF hợp lệ." |
| Answer key | No missing answers | Page load + mark ready | `ERR_REVIEW_ANSWER_KEY_INCOMPLETE`: "Answer key chưa hoàn tất." |
| Scoring | Total/per-row score valid | Page load + mark ready | `ERR_REVIEW_SCORE_INVALID`: "Cấu hình điểm chưa hợp lệ." |
| Mark ready | Backend accepts state transition | Mark-ready request | `ERR_TEMPLATE_READY_FAILED`: "Chưa thể đánh dấu đề sẵn sàng. Vui lòng thử lại." |

---

## Technical Notes

- Mark-ready should be idempotent or protected against double-click.
- Homework assignment and live exam session setup are separate flows using this template.
- Class/deadline/session-open controls must not be stored directly on the template.
