## Overview

**Page Purpose:** Cho giáo viên upload PDF đề Reading, kiểm tra file đã nhận, và chuyển sang nhập answer key.

**User Situation:** Giáo viên đã khai báo thông tin bài test và có file PDF đề Reading sẵn trên máy.

**Success Criteria:** PDF hợp lệ được upload, giáo viên thấy tên file/trạng thái rõ, có thể thay file nếu nhầm.

**Entry Points:**
- Continue from Setup step.
- Resume draft at materials step.

**Exit Points:**
- Continue to Answer Key & Scoring.
- Back to Setup.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Empty | No file selected | Dropzone prompt | Choose/drop PDF |
| Uploading | Upload in progress | Progress bar, continue disabled | Cancel if supported |
| Uploaded | File accepted | File card with success status | Preview, replace, continue |
| Error | Invalid file/upload fail | Error alert near dropzone | Retry/replace |

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| PDF file | Required for Reading | Continue | `ERR_PDF_REQUIRED`: "Upload file PDF đề Reading trước khi tiếp tục." |
| File type | `.pdf`, MIME PDF | Select/drop | `ERR_FILE_TYPE`: "Chỉ hỗ trợ file PDF." |
| File size | Within backend limit | Select/drop | `ERR_FILE_SIZE`: "File PDF vượt quá dung lượng cho phép." |
| Upload | Must complete successfully | Continue | `ERR_UPLOAD_INCOMPLETE`: "File chưa upload xong." |

---

## Technical Notes

- Store uploaded file ID on draft test.
- Do not attempt PDF parsing in MVP.
- PDF preview can show metadata/page count if available, but it is not required to continue.
