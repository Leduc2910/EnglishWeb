## Overview

**Page Purpose:** Cho giáo viên thấy tổng quan lớp/đề/kết quả và dùng navbar để vào module "Thư viện đề".

**User Situation:** Giáo viên vừa đăng nhập, muốn bắt đầu tạo hoặc dùng lại đề nhanh nhưng Dashboard không phải nơi khởi tạo chính.

**Success Criteria:** Giáo viên nhận biết trạng thái hệ thống và chuyển sang module "Thư viện đề" trong một thao tác.

**Entry Points:**
- Redirect sau đăng nhập.
- Navbar từ các trang teacher khác.

**Exit Points:**
- `/teacher/library` khi chọn module "Thư viện đề".
- `/teacher/results` khi chọn module "Kết quả".

---

## Layout Structure

```text
+--------------------------------------------------+
| App nav: Dashboard | Thư viện đề | Lớp | Kết quả |
+--------------------------------------------------+
| Page header: Chào giáo viên + term/class filter  |
+----------------+----------------+----------------+
| Summary cards  | Summary cards  | Summary cards  |
+--------------------------------------------------+
| Recent activity / cần xử lý                      |
+--------------------------------------------------+
```

**Layout intent:** Dashboard là bề mặt scan, không phải nơi khởi tạo đề. Quyết định correct-course: tạo đề đi qua module "Thư viện đề"; giao homework/thi trực tiếp là hành động tiếp theo từ đề sẵn sàng.

## Page Sections

### Section: Teacher App Navigation

|--------|------|--------------------|
| `teacher-dashboard-nav-dashboard` | Nav item | Current page, active state. |

## Interactions

| Object ID | Trigger | Behavior |
|-----------|---------|----------|
| `teacher-dashboard-nav-library` | Click | Navigate to Question/Test Library. |
| `teacher-dashboard-class-filter` | Change | Refetch/update metrics for selected class. |
| `teacher-dashboard-recent-table` | Row click | Opens template, homework/live exam, or result detail depending on row type. |

---

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Metrics fetching | Skeleton cards/table | Wait |
| Default | Metrics available | Cards and activity table | Navigate modules |
| Empty | No templates yet | Summary shows zeros, recent work empty | Use navbar "Thư viện đề" |
| Error | Dashboard data fails | Inline retry banner | Retry or navigate |

---

## Validation & Errors

| Check | Rules | Timing | Error |
|-------|-------|--------|-------|
| Teacher session | Authenticated teacher required | Page load | `ERR_TEACHER_AUTH_REQUIRED`: "Vui lòng đăng nhập lại." |
| Class filter | Must be one of teacher's classes | Change/load | `ERR_CLASS_FILTER_INVALID`: "Bộ lọc lớp không hợp lệ." |
| Metrics access | Teacher can only see own classes/templates/sessions | Data fetch | `ERR_DASHBOARD_ACCESS`: "Bạn không có quyền xem dữ liệu này." |

---

## Technical Notes

- Navbar labels are primary routing; no duplicate "Tạo đề" CTA on dashboard.
- Dashboard should remain useful but visually quiet.
- Results/Speaking metrics may be hidden if backend capability is not ready.
