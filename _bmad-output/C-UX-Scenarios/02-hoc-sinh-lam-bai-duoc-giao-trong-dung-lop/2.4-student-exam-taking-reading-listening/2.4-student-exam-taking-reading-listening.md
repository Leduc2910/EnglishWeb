## Overview

**Page Purpose:** Cho học sinh làm homework hoặc bài thi trực tiếp bằng cách xem PDF, nghe audio nếu là Listening, nhập đáp án vào form riêng, autosave và nộp bài rõ ràng.

**User Situation:** Học sinh đang trong bài làm; nếu là homework thì quan tâm hạn nộp, nếu là thi trực tiếp thì quan tâm phiên thi đang mở và thời gian còn lại.

**Success Criteria:** Học sinh hiểu đang làm bài nào, câu nào còn thiếu, đáp án được lưu, và nộp thành công với xác nhận rõ.

**Entry Points:**
- Open Reading/Listening homework or live exam from Assigned Tests.
- Resume an in-progress attempt.

**Exit Points:**
- Submission success confirmation.
- Back to Assigned Tests only after warning if unsaved/unsubmitted.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Attempt/material loading | Workspace skeleton | Wait |
| Default | Ready | PDF + answer panel visible | Work on answers |
| Autosaving | Answer changed | Autosave status active | Continue working |
| Offline/degraded | Network lost | Persistent warning, local draft retained | Keep working/retry |
| Submit warning | Missing answers | Modal lists missing count | Go back or submit anyway if allowed |
| Submitted | Submit succeeds | Success confirmation | Return to assigned tests |
| Error | Material/submit fails | Inline error with retry | Retry |

## Validation & Errors

| Check | Rules | Timing | Error |
|-------|-------|--------|-------|
| Attempt access | Student must have active assigned test | Page load | `ERR_ATTEMPT_NOT_ALLOWED`: "Bạn không có quyền làm bài này." |
| Homework access | Homework must be assigned and not closed | Page load/submit | `ERR_HOMEWORK_CLOSED`: "Homework này đã hết hạn nộp." |
| Live exam access | Live exam session must be open for class | Page load/submit | `ERR_LIVE_EXAM_NOT_OPEN`: "Bài thi trực tiếp chưa được mở." |
| Answer format | Accept text/choice values based on teacher answer key config | Input/submit | `ERR_ANSWER_FORMAT`: "Đáp án câu {n} chưa đúng định dạng." |
| Time limit | If expired, disable editing and guide submit/auto-submit | Timer | `ERR_TIME_EXPIRED`: "Đã hết thời gian làm bài." |
| Submission | Attempt not already submitted | Submit | `ERR_ALREADY_SUBMITTED`: "Bài này đã được nộp." |

## Technical Notes

- Autosave is a core UX requirement, not a nice-to-have.
- The attempt must reference either a HomeworkAssignment or LiveExamSession.
- Live exam attempts may need stricter start/end locking than homework attempts.
- Keep local draft buffer so reload/network hiccups do not destroy answers.
- Submitted answers must become read-only.
- For MVP, PDF remains source of questions; form only captures answer values.
