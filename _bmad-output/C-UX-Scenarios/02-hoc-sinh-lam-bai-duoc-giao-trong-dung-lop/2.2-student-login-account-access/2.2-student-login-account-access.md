## Overview

**Page Purpose:** Học sinh đăng nhập đúng tài khoản sau khi đã xác nhận lớp.

**User Situation:** Học sinh đã thấy tên lớp đúng và muốn vào danh sách bài, không muốn nhập lại mã lớp.

**Success Criteria:** Đăng nhập thành công, lớp đã chọn được giữ, học sinh vào đúng Assigned Tests.

**Entry Points:**
- Continue from class-code confirmation.
- Auth guard redirects here when class context exists but account session missing.

**Exit Points:**
- `/student/tests` after successful login.
- Back to `/class` if class context is wrong.

## Interactions

| Object ID | Trigger | Behavior |
|-----------|---------|----------|
| `student-login-change-class-link` | Click | Clears class context after confirmation and returns to `/class`. |
| `student-login-submit-button` | Click / Enter | Validates fields, authenticates, verifies membership in selected class, routes to assigned tests. |
| `student-login-password-input` | Enter | Submits form if identifier present. |

---

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Class context loaded | Login form + class card | Enter credentials |
| Missing class context | Direct route without code | Prompt to enter class code | Go to `/class` |
| Loading | Login pending | Submit loading, fields disabled | Wait |
| Error | Invalid login/not in class | Alert above submit | Retry/change class |
| Success | Auth accepted | Short transition | Navigate to tests |

---

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| Identifier | Required | Submit | `ERR_STUDENT_IDENTIFIER_REQUIRED`: "Nhập tài khoản học sinh." |
| Password | Required | Submit | `ERR_STUDENT_PASSWORD_REQUIRED`: "Nhập mật khẩu." |
| Membership | Student must belong to selected class | Response | `ERR_STUDENT_NOT_IN_CLASS`: "Tài khoản này chưa thuộc lớp đã chọn." |

---

## Technical Notes

- Preserve class code across login securely; re-check membership server-side.
- Do not expose class roster details on login failure.
- Avoid sending student to a generic dashboard; go straight to assigned tests.
