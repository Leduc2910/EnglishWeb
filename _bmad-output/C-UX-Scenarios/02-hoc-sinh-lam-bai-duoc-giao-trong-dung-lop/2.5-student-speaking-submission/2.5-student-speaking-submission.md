## Overview

**Page Purpose:** Cho học sinh xem đề Speaking/cue card, upload file nói, kiểm tra file, và nộp với xác nhận rõ.

**User Situation:** Học sinh đã có file nói hoặc cần xem lại yêu cầu bài Speaking trước khi upload. Nỗi lo chính là upload nhầm file hoặc không biết file đã nộp chưa.

**Success Criteria:** File hợp lệ được upload, học sinh có thể thay file trước khi nộp, và sau nộp thấy confirmation rõ với tên file/thời gian.

**Entry Points:**
- Open Speaking test from Assigned Tests.
- Resume draft submission before final submit.

**Exit Points:**
- Submission success confirmation.
- Back to Assigned Tests.

**Layout intent:** Prompt and upload status stay side by side so học sinh can verify they are submitting the right file for the right prompt.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Empty | No file selected | Prompt visible + upload zone | Choose file |
| Uploading | File upload pending | Progress bar, submit disabled | Wait/cancel if available |
| Uploaded draft | File uploaded but not submitted | File card + submit enabled | Replace/submit |
| Error | Invalid file/upload fail | Inline alert near upload | Retry/replace |
| Submitted | Final submit succeeds | Success panel, read-only file card | Return to tests |

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| Speaking file | Required before submit | Submit | `ERR_SPEAKING_FILE_REQUIRED`: "Chọn file nói trước khi nộp." |
| File type | Must match allowed audio/video types | Select/drop | `ERR_SPEAKING_FILE_TYPE`: "Định dạng file chưa được hỗ trợ." |
| File size | Must be under backend limit | Select/drop | `ERR_SPEAKING_FILE_SIZE`: "File vượt quá dung lượng cho phép." |
| Submission | Test must still be open and not already submitted | Submit | `ERR_SPEAKING_SUBMIT_BLOCKED`: "Chưa thể nộp file này. Kiểm tra hạn nộp hoặc trạng thái bài." |

---

## Technical Notes

- Uploading a file is not the same as final submission; UI must distinguish uploaded draft vs submitted.
- Store file ID on draft submission and lock it after final submit.
- Speaking is manually graded by teacher; no AI grading language appears in student UI for MVP.
