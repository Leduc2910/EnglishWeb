## Overview

**Page Purpose:** Hiển thị đúng **homework** và **bài thi trực tiếp** trong lớp đã chọn, với trạng thái rõ để học sinh mở đúng bài.

**User Situation:** Học sinh vừa đăng nhập, muốn thấy ngay bài cần làm và hiểu bài đó là homework có hạn nộp hay bài thi trực tiếp đang/chưa mở.

**Success Criteria:** Học sinh nhận ra đúng lớp, đúng dạng bài, deadline/phiên thi, trạng thái, và mở bài cần làm không nhầm.

**Entry Points:**
- Redirect after student login.
- Return from exam/submission screen.

**Exit Points:**
- Reading/Listening exam screen.
- Speaking submission screen.
- Submitted result/confirmation view if opening completed item.

## Interactions

## Validation & Errors

| Check | Rules | Timing | Error |
|-------|-------|--------|-------|
| Class context | Required and must match student membership | Page load | `ERR_CLASS_CONTEXT_MISSING`: "Chưa có lớp hiện tại. Nhập lại mã lớp." |
| Test access | Test must be assigned to active class/student | Open test | `ERR_TEST_NOT_AVAILABLE`: "Bài này không còn khả dụng trong lớp hiện tại." |
| Homework deadline | If closed, cannot start new homework attempt | Open homework | `ERR_HOMEWORK_CLOSED`: "Homework này đã hết hạn nộp." |
| Live exam session | Must be open for the student's class | Open live exam | `ERR_LIVE_EXAM_NOT_OPEN`: "Bài thi trực tiếp chưa được mở." |

---

## Technical Notes

- Query homework assignments and live exam sessions by active class and authenticated student, not only by class code.
- Keep submitted tests visible; hiding them makes students anxious about whether submission worked.
- Status definitions must match backend submission states.
