## Overview

**Page Purpose:** Học sinh nhập mã lớp, xác nhận đúng lớp, rồi tiếp tục sang đăng nhập học sinh.

**User Situation:** Học sinh vừa nhận mã lớp từ giáo viên và có thể hơi căng vì sợ vào nhầm lớp hoặc không thấy bài.

**Success Criteria:** Mã lớp hợp lệ được nhận diện, tên lớp/giáo viên hiển thị rõ, và context lớp được giữ khi sang login.

**Entry Points:**
- Học sinh mở EnglishTestWeb từ trình duyệt.
- Link lớp hoặc hướng dẫn từ giáo viên.
- Reload khi chưa có session lớp.

**Exit Points:**
- `/student/login?classCode={code}` khi mã lớp hợp lệ.
- Ở lại trang với lỗi rõ nếu mã không hợp lệ/hết hạn.

## Interactions

| Object ID | Trigger | Behavior |
|-----------|---------|----------|
| `student-class-entry-code-input` | Input | Normalizes spaces/dashes, visually uppercases, keeps raw value safe. |
| `student-class-entry-submit-button` | Click / Enter | Validates code format, looks up class, shows confirmation card. |
| `student-class-entry-confirm-button` | Click | Stores class context and navigates to student login. |
| `student-class-entry-change-code-button` | Click | Clears class result, focuses code input. |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Page loaded | Empty code input | Enter code |

## Validation & Errors

| Field | Rules | Timing | Error |
|-------|-------|--------|-------|
| Class code | Required | Submit | `ERR_CLASS_CODE_REQUIRED`: "Nhập mã lớp." |
| Class code | 4-12 alphanumeric chars after normalization | Submit | `ERR_CLASS_CODE_FORMAT`: "Mã lớp chưa đúng định dạng." |
| Class lookup | Must match active class | Response | `ERR_CLASS_CODE_INVALID`: "Không tìm thấy lớp với mã này." |

---

## Technical Notes

- Store class context in session/local state before login, but revalidate server-side after login.
- Do not show assigned tests before authentication.
- Confirmation card is important; it defuses the "nhập nhầm lớp" fear.
